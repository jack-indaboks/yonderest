# Yonderest roadmap

This roadmap says when features arrive. What each feature is belongs to [DESIGN.md](DESIGN.md), the game as it currently runs is described in [README.md](README.md), and what each tagged version changed is in [CHANGELOG.md](CHANGELOG.md). Milestones are playable outcomes, not dates.

## Next: polish, then going public

- Holding W to reach up and shuffle along the wall.
- One forgiveness rule for jumps and placement.
- Taking back an object from the character's own space.
- New kinds of object readied automatically.
- Subdued unselected entries in the belt's ring.
- A brief transformation when a craft completes.
- The wall shuffle, upward strike and leapfrog poses.
- Documents that agree with the game and with each other.

The repository becomes public at the end of this pass.

## Then: the first playable release

1. **A richer world.** The varied rear layer with its own resources, the backdrop behind it, and landscape features at their own scale, so that worlds can grow to the starting world's intended size. Generation changes that reshape land settle at their boundaries with saved territory.
2. **Carrying and storage.** The finite backpack, stack sizes and in-world storage.
3. **Reasons to travel.** Several distinct biomes, a broader range of materials and construction, a module configuration players can use, and reliable return journeys across a world worth inhabiting.

## The connected universe

Portals, additional persistent worlds and their different resource ecosystems, making homes and outposts a geography that spans worlds.

## Unsequenced

Lua scripting arrives when there is gameplay worth scripting. Deeper underground environments, sky biomes, other platforms, two players on one screen, and everything under DESIGN's Possibilities have no place in the sequence yet. Each gets its own scope when it is taken up.
